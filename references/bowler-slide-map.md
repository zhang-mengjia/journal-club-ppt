# Bowler 参考稿逐页读法

下表按 53 张幻灯片的实际放映顺序编号。插页的页脚编号可能不同。用它查某个写作或排版决定在汇报里怎样起作用。新论文的图数、分组和讲述顺序取决于其证据。

## 正式开场与背景

| 页 | 内容 | 文字和图怎样配合 |
| --- | --- | --- |
| 1 | RNN 与动力学分析导读图 | 单幅居中图，图内已有文字；属于封面前的选用材料。 |
| 2 | 动力学类型示意 | 单幅对照图，让需要预习的听众先熟悉固定点和轨迹形态。 |
| 3 | 正式标题页 | 灰色横带中居中放论文原题，按语义换行。下方依次列正式署名、期刊卷页年份和 Journal Club。新稿从此页型开始。 |
| 4 | 通讯作者履历 | 黑色标题栏写 Corresponding author，人名作小标题。圆形肖像下写机构，右侧按年份列教育、研究训练与任职。新稿若合页介绍多位通讯作者，黑栏用 Corresponding authors。 |
| 5 | 通讯作者的 Neurotree | 黑栏写 Corresponding author，小标题写 Neurotree。导师在上、受训者在下，连线旁写训练身份。博士、博士后和研究助理分支分别标明。新稿覆盖论文的每位通讯作者。 |
| 6 | 通讯作者实验室 | 同一黑栏下换用实验室名作小标题。用图片和三条短语交代科学问题、行为范式与技术。 |
| 7 | 海马位置细胞 | 领域名词作小标题。原始记录、放电示意、人物和获奖信息各配短标签，论文引文放在实验图旁。 |
| 8 | MEC 网格细胞 | 与第 7 页平行排列。同样的视觉位置可直接对照两种放电图样。 |
| 9 | 虚拟门等待范式 | 先交代虚拟环境、停跑规则和记录方式。页上用任务名和原图，具体时长在讲稿中说明。 |
| 10 | MEC 时间细胞 | 接着展示单细胞与群体序列，两图用同一条原文引文。小标题仅点出细胞类型。 |
| 11 | 气味时长判别范式 | 换一项背景研究，先用实验原图说明任务条件和反应规则。 |
| 12 | 情境依赖的时间表征 | 单个关键 panel 支撑本页主题，详细比较留给讲稿。 |
| 13 | MEC 干预与计时学习 | 小标题直接写行为结论，配干预设计和行为数据，由此引出研究问题。 |
| 14 | Question | 黑栏下仅放一个居中的完整问句，概括经历、策略和神经动力学之间的关系。 |
| 15 | Outline | 一级用动名词短语介绍三组研究做法，二级用简短陈述句概括对应结果。作者介绍、背景与讨论无需进入结果提纲。 |

## 第一组结果

第 17–32 页的四条黑色大标题依次统领行为、表征、连接与动力学。竖线左侧是同一组多页反复使用的主题，右侧指出本页的具体比较。一次性任务名或独立陈述直接成题。图旁如需补一句发现，内容应来自该页能展示的证据。

| 页 | 内容 | 文字和图怎样配合 |
| --- | --- | --- |
| 16 | 第一组进入页 | Summary 沿用 Outline 的一级条目。本组用蓝色，后续用浅灰色，本组结果在讲完后展开。 |

| 30 | 两种策略的比较 | 用 Fig. 4e,f 引入泄漏积分与检测加计时两种解法。 |
| 31 | 同一比较的续页 | 延用第 30 页的小标题和 Fig. 4e,f；本页用两个图对象呈现。只在需要继续讲同一证据时采用这种续页。 |
| 32 | 新刺激时长 | Dynamics 系列最后用 Fig. 4g–j 检查策略对未见刺激的反应。 |
| 33 | 第一组总结 | 当前一级标题及其四条结果用蓝色展开，未来的组仍只显示浅灰色一级标题。 |

## 第二组与第三组结果

| 页 | 内容 | 文字和图怎样配合 |
| --- | --- | --- |
| 34 | 第二组进入页 | 上组标题和结果转黑，本组一级标题转蓝，讲稿介绍将比较的预训练方案。 |
| 35 | 第一种单一时序预训练 | 本组黑栏同时涵盖 RNN 与动物。小标题直接陈述改变训练方案会影响 RNN 行为，配 Fig. 5a–c。 |
| 36 | 第二种单一时序预训练 | 延用上页的完整小标题，Fig. 5e–g 换成另一种训练经历，形成连续对照。 |
| 37 | RNN 表征比较 | 大标题延续，小标题的对象从行为换为表征，配 Fig. 5d,h。 |
| 38 | 动物训练和记录 | 在同一黑栏下，用独立名词短语交代动物流程并就近加入电极位置验证（Fig. 6a、Extended Data Fig. 9a,b）。 |
| 39 | 小鼠行为个例 | 小标题用动物行为的结果句，以 Fig. 6c 的个例起讲。 |
| 40 | 小鼠群体行为 | 沿用前页陈述式小标题，Fig. 6b,d 补上组水平比较。 |
| 41 | 小鼠神经表征 | 陈述式小标题换为动物神经表征，Fig. 6j,k 展示低维群体结构。 |
| 42 | 小鼠跨条件解码 | 延用前页小标题。Fig. 6f–h 配一个短标签提示解码方法，讲稿交代记录场次与动物数。 |
| 43 | 第二组总结 | 用同一条阶段结果收拢模型与动物比较。第一组转黑，当前组转蓝，下一组保留浅灰一级标题。 |
| 44 | 第三组进入页 | 保留已讲两组的黑色条目，第三组只亮出研究步骤，讲稿提出新试次的预测问题。 |
| 45 | RNN 对新试次的反应 | 同一黑栏统领此后三页。直接命名预测对象，用 Fig. 7a,c 交代新试次与模型反应。 |
| 46 | RNN 在新试次中的动力学 | Extended Data Fig. 7b 独立成页，放在行为预测和动物检验之间解释模型依据。 |
| 47 | 动物对新试次的反应 | 小标题的对象转为动物，用 Fig. 7b,e–g 检查对应预测。 |
| 48 | 第三组总结 | 三组结果全部可见。当前组保持蓝色，此前组为黑色，随后转入 Discussion。 |

## 讨论与结束

| 页 | 内容 | 文字和图怎样配合 |
| --- | --- | --- |
| 49 | 论文 Discussion | 小标题沿用研究主题，三个同级方框条目依次写训练经历的解释、促进或妨碍后续学习的可能，以及模型在设计训练流程中的用途。 |
| 50 | RNN 建模方法延伸 | 小标题改为这项延伸的具体主题。按四种建模用途分组，每组附代表性原始研究。 |
| 51 | 动力系统方法延伸 | 先讲模型辨识，再讲动力学分析。两级条目区分工作步骤、模型类别与分析方法。 |
| 52 | 致谢 | 灰色横带中居中写 Thanks!，下方保留 Journal Club，讲稿简短收尾。 |
| 53 | 附图 | 致谢后单独放一幅 RNN 模型与符号说明图，供按需解释。新稿可在致谢处结束。 |
